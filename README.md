# CampusSpend 大学生消费记录与行为分析系统

## 一、项目简介

CampusSpend 是一个基于 Flask + SQLite 的大学生日常消费记录与行为分析系统。

本项目用于记录大学生日常消费数据，并通过统计指标和图表分析消费结构与消费趋势。用户可以添加、查看、编辑、删除消费记录，系统会自动统计总消费金额、消费记录数量、必要消费金额、非必要消费金额，并通过 ECharts 展示分类消费占比图和每日消费趋势图。

本项目是我在学习 Python Web 开发、SQLite 数据库和数据可视化过程中完成的第一个完整项目，主要用于练习 Web 项目基本结构、数据库增删改查、统计分析和 Git 版本管理流程。

---

## 二、功能列表

### 1. 消费记录管理

- 添加消费记录
- 查看消费记录列表
- 编辑消费记录
- 删除消费记录

### 2. 消费数据统计

- 统计总消费金额
- 统计消费记录数量
- 统计必要消费金额
- 统计非必要消费金额
- 按消费分类统计金额

### 3. 数据可视化

- 分类消费占比饼图
- 每日消费趋势柱状图

### 4. 页面展示

- 首页数据看板
- 添加消费页面
- 编辑消费页面
- 统一 CSS 页面样式
